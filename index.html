ملخص تفاعلي: بناء الواجهات الرسومية بلغة البايثون

النموذج البرمجي تكينتر (tkinter) — بطاقات مراجعة، محاكي رسم فوري، وتدريبات تفاعلية

مفهوم واجهة المستخدم (GUI) وتكينتر

واجهة المستخدم الرسومية (GUI): تسمح بالتفاعل مع الحاسب باستخدام الصور والرموز والعناصر الرسومية بدلاً من النص فقط.

نموذج تكينتر (tkinter): يحتوي على نصوص برمجية ودوال جاهزة للرسم على لوحة الرسم القماشية (Canvas) وهي منطقة مستطيلة مخصصة للرسومات والتخطيطات.

القالب الأساسي لإنشاء نافذة رسم

from tkinter import *
window = Tk()
window.title("Graphics Window")
canvas = Canvas(bg="teal", width=400, height=400)
canvas.pack()
window.mainloop()

جدول الأوامر الأساسية

الأمر البرمجي الوظيفة والوصف
from tkinter import * يستورد نموذج تكينتر البرمجي بجميع دواله.
window = Tk() ينشئ نافذة أساسية جديدة على الشاشة لعرض الرسومات.
window.title("...") يحدد عنواناً لنافذة الرسومات.
canvas = Canvas(bg="color", width=500, height=350) يضبط حجم (العرض والارتفاع) ولون الخلفية للوحة الرسم القماشية.
canvas.pack() يضع كل العناصر ويعرضها داخل النافذة.

الألوان في بايثون (RGB & الأسماء المعيارية)

يمكن تحديد الألوان بطريقتين:

  • اسم لون معياري: مثل أبيض، أسود، أحمر، أزرق، أخضر، سماوي، أصفر، أرجواني.
  • نموذج ألوان RGB: 3 أرقام صحيحة بين 0 و 255 تحدد كثافة (الأحمر، الأخضر، الأزرق).
Crimson(220, 20, 60)
Coral(255, 127, 80)
Teal(0, 128, 128)
SteelBlue(70, 130, 180)
Purple(128, 0, 128)

نظام الإحداثيات في لوحة الرسم (Canvas)

يُقاس بالبكسل كأعداد صحيحة، ويختلف عن النظام الديكارتي المعتاد:

  • تقع نقطة الأصل (0, 0) في الزاوية اليسرى العليا من اللوحة.
  • محور X: تزداد قيمته كلما اتجهنا إلى اليمين.
  • محور Y: معكوس، تزداد قيمته كلما اتجهنا إلى الأسفل.

حرك الفأرة داخل اللوحة التجريبية أدناه لاستكشاف الإحداثيات:

(x = 0, y = 0)

1. رسم الخطوط والمثلث create_line

يرسم خطاً بين نقطة البداية ونقطة النهاية، ويمكن تمرير عدة نقاط لرسم مثلث.

# خط ملون وعريض
canvas.create_line(10,10, 100,100, width=5, fill="red")

# خط متقطع
canvas.create_line(0,100, 400,100, fill="white", dash=100)

# رسم مثلث بالخطوط
canvas.create_line(240,20, 160,100, 320,100, 240,20)

2. رسم المستطيل create_rectangle

يُحدد بإحداثيات الزاوية اليسرى العليا (x1,y1) والزاوية اليمنى السفلية (x2,y2).

canvas.create_rectangle(
    100, 150, 400, 250,
    width=3,
    outline="coral",
    fill="white"
)

fill: لون التعبئة الداخلي | outline: لون الإطار الخارجي | width: سُمك الإطار.

3. الشكل البيضاوي والدائرة create_oval

يتسع داخل المستطيل المحدد بالإحداثيات (x1,y1, x2,y2). إذا كان المستطيل مربعاً ينتج دائرة.

# رسم دائرة (العرض 250 والارتفاع 250)
canvas.create_oval(50, 50, 300, 300, width=3)

4. رسم المضلع create_polygon

شكل مستوٍ مغلق يتكون من عدة خطوط مستقيمة متصلة تُحدد نقاط زواياها في قائمة.

points = [100,80, 180,80, 220,150, 180,220, 100,220, 60,150]
canvas.create_polygon(points, fill="green")

ربط الأحداث بالدوال widget.bind()

يمكن ربط عناصر الواجهة بأحداث الفأرة أو لوحة المفاتيح لاستدعاء دالة معينة عند وقوع الحدث:

def callback(event):
    print("clicked at", event.x, event.y)

canvas = Canvas(bg="teal", width=400, height=400)
canvas.bind("<Button-1>", callback)
canvas.pack()
